## Configuration Files

- `package.json`
  - Defines the project as a private Node.js CAP application.
  - Uses ESM via `"type": "module"`.
  - Provides `"start": "cds-serve"` for running the CAP server.
  - Includes HANA and SQLite dependencies for production and local development readiness.

- `mta.yaml`
  - Defines the MTA ID `SmartProcureX`.
  - Enables parallel deployments.
  - Configures the MTA build to run `npm ci` and `npx cds build --production`.
  - Defines `SmartProcureX-srv` as the Node.js CAP service module.
  - Defines `SmartProcureX-db-deployer` as the HANA deployment module.
  - Defines `SmartProcureX-db` as an SAP HANA HDI container resource using the `hdi-shared` plan.

- `.gitignore`
  - Keeps generated and local-only files out of source control, including `node_modules/`, `gen/`, `mta_archives/`, local SQLite databases, and private CAP configuration.

- `.vscode/tasks.json`
  - Adds a local VS Code task for `cds watch`.
